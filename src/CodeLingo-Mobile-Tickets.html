Everything needed to rebuild the CodeLingo web app on mobile against the same backend. Each ticket says what to build, which API calls it uses, which web code can be copied, and how to know it is finished.

Before you start

The API address changes on a phone

The web app calls http://localhost:3000. On a real phone, use your computer's local network IP. On the Android emulator, use 10.0.2.2:3000. Keep it in one env variable (MOB-2).

Four response shapes are guesses

The web code guesses the responses of /auth/register, /auth/me, /me/onboarding and /diagnostic/result. Call them once in Postman or read the backend repo, then write the real shapes into MOB-2.

Lessons, XP and editor do not exist yet

The web app has no lessons, practice, XP, logout or profile-update endpoints. Those tickets are in the Blocked group at the bottom. Do not start them yet.

Backend reference

The 8 endpoints the web app uses today. All base URL http://localhost:3000. Auth is a Bearer token in the Authorization header. No cookies.
