CodeLingo / web app

Lesson feature tickets

Next step for the web app: Duolingo-style lessons. A user opens a lesson from the syllabus, answers short exercises one at a time, gets instant feedback, and earns XP and a streak. Each ticket says what to build, which API calls it uses and how to know it is finished.

Before you start

Agree on the data format first

Both of you depend on the exercise payloads and endpoints in this page. Settle them in LES-3 before coding. The frontend can start with a local mock JSON file while the backend catches up.

Grading happens on the server

The browser must never receive the correct answers. It sends an answer, and the server replies correct or wrong with an explanation. This is also what keeps XP honest.

Fix three web problems first

The web app repeats its base URL in 8 places, has no route guard and has no logout. LES-1 and LES-2 fix that so every new lesson call goes through one client.

Check against your existing plan

Your repo has a plan with tickets SYL-11 to SYL-20 that I have not seen. These tickets overlap it. Merge or renumber as you like. The backend tickets do not assume a specific ORM or framework.
